# PRIMETOUCH website (React + Vite)

```
npm install
npm run dev      # local preview
npm run build    # production build in /dist
```

Deploy the `dist` folder to Netlify or Vercel (redirect files for page routing are included).

## Where things are
- `src/pages/` – one file per page (Home, About, Services, HowItWorks, FAQ, Contact)
- `src/components/` – Header, Footer, CtaBanner, QuoteButton, Icon, ScrollToTop
- `src/data/` – services, FAQs, phone/email, Google Form quote link (`site.js`)
- `src/styles/` – global, layout, home, pages, responsive CSS
- `src/assets/` – logo and photos (replace with higher-resolution exports from Figma, same file names)
